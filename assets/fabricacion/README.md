# Imágenes de fabricación

Material recibido para la primera etapa visual de Herraidea el 8 de septiembre de 2026.

- `torno-cnc-haas.jpg`: imagen vertical para comunicar maquinado CNC.
- `produccion-postes.jpg`: imagen vertical para presentar producción de postes y sistemas de barandal.
- `empaque-herraidea.jpg`: imagen horizontal para cobertura, preparación y envío.

Las imágenes se optimizaron a JPEG para la web. Funcionan como material visual proporcionado para el proyecto; los textos públicos asociados se limitan a capacidades y mercados confirmados en `docs/FASE_1_DEFINICION.md`.
