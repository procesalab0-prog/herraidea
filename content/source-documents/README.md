# Documentos fuente

Archivos originales recibidos de Herraidea para consulta, conciliación de información y construcción del nuevo sitio.

- `catalogo-herraidea-2023.pdf`: catálogo original de 12 páginas recibido el 8 de septiembre de 2026.
- `Herraidea-Esquina-90-3D.zip`: paquete original de la esquina articulada del sistema HRD 1518.
- `Herraidea-Barandal-Cables-Esquina.zip`: paquete original del sistema HRD 1616 de poste cuadrado y cable de acero.
- `hrd-1616/portada-estudio.png`: última portada oficial recibida para el HRD 1616.

Estos documentos se conservan sin modificaciones. Su contenido debe contrastarse con la información vigente antes de publicarse.
