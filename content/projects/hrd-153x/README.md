# HRD 1533 / 1534 / 1535

Estudio fotográfico de la familia HRD 1533 / 1534 / 1535 en acero satinado: perfil con canales, empaques, base cuadrada y soporte de pasamanos. Correspondencia por código y medidas pendientes de confirmar.

Se representa un perfil intermedio como estudio común, sin asignarlo a un código individual. Geometría interior, altura de 900 mm, sección de 60 mm, base de 105 mm son proporciones visuales provisionales, no cotas recibidas. No se incluye la tarima negra del exhibidor. Acabado acero pedido por el usuario; empaques oscuros.

El usuario confirma vidrio de 10 mm y vinil de empaque incluido. Se mantiene una única familia en la calculadora sin asignar códigos a posiciones. Esquina geométrica provisional con dos canales a 90 grados; no representa una ficha de fabricación validada.
