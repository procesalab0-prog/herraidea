## Alcance confirmado

El GLB final contiene 190 nodos independientes y una animación llamada `Despiece`, con el proyecto ensamblado al inicio y separado al final. La web permite girar, acercar, separar, volver a armar y observar un costado de cerca. Los cristales laterales son piezas continuas con recorte inferior redondeado.

## Restricción de uso

Es una reconstrucción visual aproximada creada a partir de fotografías. No debe presentarse como modelo de fabricación, plano dimensional ni secuencia física de ensamble hasta recibir y validar la información técnica de Herraidea.
