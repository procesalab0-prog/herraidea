## Presentación aprobada

El sistema se identifica como **HRD 1616 · poste cuadrado + cable de acero**. El archivo fuente conserva intacta su geometría y animación `Despiece`. En la web, el material negro de los postes se sustituye durante la visualización por el mismo acabado de acero inoxidable satinado de las demás piezas; esta sustitución no modifica el GLB original.

La portada vigente es la última imagen proporcionada por Herraidea: muestra los cables entrando directamente al poste y reemplaza cualquier referencia visual anterior con terminales exteriores.
