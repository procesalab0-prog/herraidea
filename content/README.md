# Contenido migrado de Jimdo

Este directorio conserva tanto el respaldo original como una versión estructurada lista para reutilizar en el sitio o en herramientas de diseño.

- `catalog/products.json`: índice resumido de los 66 productos.
- `catalog/details.json`: fichas completas con descripción, especificaciones, imágenes técnicas, texto original y referencia a la página respaldada.
- `catalog/images/`: imágenes principales optimizadas para el catálogo.
- `about.json`: historia, misión, visión, valores e imagen institucional.
- `jimdo-backup/pages/`: HTML original de todas las páginas públicas descargadas.
- `jimdo-backup/assets/`: imágenes originales y diagramas técnicos descargados.
- `jimdo-backup/pages.json` y `assets.json`: relación entre URL original y archivo local.

La web no consulta Jimdo en tiempo de ejecución. Todos los textos e imágenes utilizados se sirven desde este repositorio.
