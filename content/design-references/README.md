# Referencias visuales

Inspiración proporcionada para orientar la evolución visual de Herraidea. Estas imágenes se conservan como referencias de composición, tratamiento de materiales y presentación de producto; no deben copiarse literalmente ni publicarse como contenido propio.

- `01-tipografia-editorial.jpeg`: jerarquía tipográfica editorial, composición asimétrica y contraste blanco/negro.
- `02-hardware-modular.jpeg`: organización modular, precisión industrial y controles físicos ordenados.
- `03-acero-cepillado-macro.jpeg`: acero cepillado, reflejos controlados y encuadre macro.
- `04-producto-mecanismo-detalle.jpeg`: producto abierto, mecanismo visible y sensación de precisión.

La identidad final conservará los colores vigentes de Herraidea: negro grafito, blanco, grises metálicos y rojo de marca.
