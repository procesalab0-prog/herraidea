# Migración de contenido de Herraidea

Copia de solo lectura obtenida de `https://www.herraidea.com/` para reconstruir el sitio fuera de Jimdo. La web original no fue modificada.

## Contenido listo para usar

- `content/catalog/products.json`: catálogo estructurado con 66 registros, categorías, claves, nombres, imagen local y URL de la ficha original.
- `content/catalog/images/`: imágenes del catálogo con nombres legibles basados en la categoría y la clave del producto.
- `content/jimdo-backup/pages/`: respaldo HTML de 71 páginas públicas, incluidas las fichas técnicas individuales.
- `content/jimdo-backup/assets/`: 223 recursos gráficos originales localizados en las páginas de Jimdo.
- `content/jimdo-backup/pages.json`: relación entre las URL originales y los archivos HTML guardados.
- `content/jimdo-backup/assets.json`: relación entre las URL originales y los archivos gráficos guardados.
