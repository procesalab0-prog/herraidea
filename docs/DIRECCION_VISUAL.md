# Dirección visual — Herraidea

Documento de referencia para convertir la inspiración recibida en un sistema visual propio, elegante y coherente con la landing actual.

Estado: **dirección inicial aprobada como inspiración**  
Fecha: 2026-09-08

## 1. Sensación buscada

- Elegancia industrial.
- Precisión y calidad de fabricación.
- Tecnología presentada de manera limpia y accesible.
- Producto como protagonista.
- Composición editorial con carácter, sin perder claridad comercial.

La web no debe sentirse como una ferretería tradicional ni como un catálogo saturado. Debe acercarse a la presentación de una marca de diseño industrial capaz de resolver proyectos a la medida.

## 2. Paleta que se conserva

- Negro grafito actual: `#0b0d10`.
- Rojo Herraidea: `#fa1418` y rojo institucional `#f10001`.
- Blanco para contraste y limpieza visual.
- Gris papel actual: `#f5f6f7`.
- Gamas de acero inoxidable para imágenes, modelos 3D y detalles.

El rojo seguirá funcionando como acento: llamadas a la acción, indicadores, subrayados, progreso y momentos puntuales de animación. No debe convertirse en un fondo dominante en todas las secciones.

## 3. Tipografía editorial

De la referencia tipográfica se toma:

- Encabezados de gran escala con pocas palabras.
- Contraste entre pesos muy negros y pesos ligeros.
- Composición asimétrica y bloques alineados con intención.
- Datos secundarios pequeños, espaciados y ordenados.
- Uso de bloques negros para destacar cifras o mensajes concretos.

Se mantendrán inicialmente Archivo y Archivo Narrow, ya presentes en la landing. La personalidad se conseguirá mediante escala, peso, espaciado y composición antes de incorporar una tipografía nueva.

Los textos protagonistas deberán ser breves y directos, por ejemplo:

- **Lo hacemos a tu medida.**
- **Tu proyecto no termina en el catálogo.**
- **Del plano a la pieza.**
- **Barandales diseñados para cada espacio.**
- **Acero, precisión y soluciones.**

## 4. Presentación del hardware y los productos

Las referencias de producto proponen:

- Encuadres macro que permitan apreciar cepillado, pulido, uniones, tornillos y tolerancias.
- Fondos blancos o gris cálido muy claro.
- Iluminación amplia y suave con reflejos controlados.
- Sombras discretas que den volumen sin volver dramática la imagen.
- Composiciones frontales o geométricas para comunicar precisión.
- Vistas abiertas o despieces cuando ayuden a explicar cómo funciona una solución.
- Repetición modular de componentes para mostrar familias, sistemas armados o piezas relacionadas.

El acabado mostrado debe corresponder al producto real. No se convertirán piezas satinadas en cromadas ni se inventarán mecanismos, perforaciones o componentes únicamente para lograr una imagen más llamativa.

## 5. Traducción propuesta a la interfaz

- Alternar secciones muy limpias con bloques negros de alto contraste.
- Usar titulares grandes como transiciones narrativas entre soluciones, fabricación y catálogo.
- Presentar cada familia como un sistema ordenado, no solo como una cuadrícula de tarjetas.
- Incorporar acercamientos de material al abrir una ficha o avanzar por una solución.
- Mostrar productos relacionados como módulos que forman un sistema completo.
- Reservar composiciones tipo tablero o bandeja técnica para despieces, calculadora y fichas de soluciones.
- Utilizar líneas finas, numeración, pequeñas etiquetas técnicas y movimiento suave para reforzar precisión.

## 6. Movimiento y teléfono

- Los titulares pueden revelarse por líneas o cambios de peso durante el desplazamiento.
- Los acercamientos de producto pueden desplazarse lentamente o cambiar de detalle sin perder el centro visual.
- La transición entre vista general, macro y despiece debe ser suave.
- En teléfono, los titulares deben tener saltos de línea diseñados y no depender de cortes automáticos.
- Los bloques protagonistas ocuparán gran parte de la pantalla, pero siempre dejarán visible la acción o la siguiente pista de desplazamiento.
- Se respetará `prefers-reduced-motion` y la legibilidad tendrá prioridad sobre el efecto.

## 7. Límites de la referencia

- No copiar logotipos, textos, iconos ni la composición exacta de las imágenes recibidas.
- No utilizar estas imágenes como fotografías de productos Herraidea.
- No introducir colores ajenos que compitan con el rojo institucional.
- No sobrecargar la interfaz con perillas, controles falsos o decoración técnica sin función.
- No sacrificar información técnica, navegación o conversión por una composición experimental.

## 8. Aplicación recomendada

Esta dirección puede utilizarse en:

1. Mensajes de transición y encabezados de secciones.
2. Presentación de barandales y fabricación a la medida.
3. Fichas de producto y acercamientos de acero inoxidable.
4. Sistemas armados, despieces y productos relacionados.
5. Canalizador de proyectos y calculadora.
6. Contenido para arquitectos, constructores y vidrieros.

Las referencias originales están archivadas en `content/design-references/` para que Codex, Claude y futuros colaboradores compartan el mismo contexto visual.

## 9. Evolución 3D acordada

El recorrido 3D deberá dejar de presentar las piezas aisladas como mensaje principal y explicar un barandal o proyecto completo. Se propone un despiece animado, recuadros técnicos para los modelos existentes, crecimiento del sistema para representar fabricación a la medida y una transición material hacia acero inoxidable satinado. Esta evolución se implementará posteriormente conforme a `docs/RECORRIDO_3D_SOLUCIONES.md`.
